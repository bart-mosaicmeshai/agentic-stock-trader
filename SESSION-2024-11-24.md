## Major Issues Fixed

### 1. Historical Data Ordering Bug 🐛 CRITICAL

**Problem**: The backtest was using stale prices from months ago instead of current prices for analysis.

**Root Cause**:
- Historical data was stored in descending order (newest first)
- `getHistoricalPricesUpToDate()` was taking the first 100 items
- Analysis server expected ascending order (oldest first), with current price at the end
- Result: Analysis was seeing prices from July when backtesting September-November

**Impact**:
- Strategy analyzed wrong prices (e.g., seeing $209 when actual price was $238)
- All signals showed "downtrend" even during strong bull markets
- Zero BUY signals generated despite favorable market conditions

**Fix**:
```javascript
// Before (WRONG):
return allPrices.filter(p => p.date <= date).slice(0, 100);

// After (CORRECT):
const filtered = allPrices.filter(p => p.date <= date);
return filtered.reverse().slice(-100); // Oldest first, current at end
```

**Files Fixed**:
- `src/backtest.js:265-274`
- `src/backtest-local.js:388-397`

**Verification**:
- Before fix: All signals showed stale prices (AAPL analysis showed $209.95 when actual was $238.15)
- After fix: Correct prices used, BUY signals generated with 100% confidence

### 2. Environment Variable Override Issue 🎯

**Problem**: `.env` file changes not being picked up by scripts.

**Root Cause**:
- Shell-level environment variables were set (probably from manual `export` commands)
- Shell variables take precedence over `.env` file values
- Variables persisted for entire terminal session

**Symptoms**:
- `WATCHLIST` showed `['AAPL']` instead of 5 stocks
- `MIN_CONFIDENCE` showed `0.5` instead of `0.25`
- Changes to `.env` file had no effect

**Solution**:
1. Identified issue by testing in fresh terminal (worked correctly)
2. Unset shell variables: `unset WATCHLIST MIN_CONFIDENCE MAX_POSITION_SIZE`
3. Added documentation and troubleshooting steps
4. Created `test-env.js` for quick environment verification

**Prevention**:
- Added warning in documentation about shell variable precedence
- Documented how to check: `env | grep MIN_CONFIDENCE`
- Added troubleshooting section in README

### 3. Insufficient Historical Data for Backtests

**Problem**: Backtest starting Aug 1 had 0 trades, returned "No signal" for all stocks.

**Root Cause**:
- Backtest requires 50+ days of historical data for indicator calculation (SMA50, RSI, MACD)
- Free Alpha Vantage tier provides ~100 days starting July 7, 2025
- Starting backtest on Aug 1 = only 20 days of prior data
- Code correctly skipped analysis: "not enough data (need 50, have 20)"

**Solution**:
- Start backtests around Sep 15-16 (50+ days after July 7)
- Updated documentation to explain warmup period requirement
- Added clear error messages showing data point count

### Architecture Notes

**Key Learning**: The importance of data ordering in time-series analysis systems.

**Design Pattern**:
- MCP servers expect chronological data (oldest → newest)
- Historical data caches store reverse chronological (newest → oldest)
- Always reverse and slice when passing to analysis

**Backtest Requirements**:
- Minimum 50 trading days warmup for indicators
- SMA50 needs 50 data points
- RSI needs 14+ data points plus warmup
- MACD needs 26+ data points plus warmup

## Lessons Learned

1. **Data ordering matters critically** in time-series analysis
   - Always verify array order expectations
   - Test with known data to verify correctness

2. **Environment variables silently override .env files**
   - Easy to miss during development
   - Need tools to verify actual values being used

3. **Indicator warmup periods are essential**
   - Can't start backtests immediately
   - Need clear documentation of requirements

4. **LLM agents think differently than rule-based**
   - More nuanced decision making
   - Can be overly conservative
   - Better at explaining reasoning

5. **Free API tier limitations require careful planning**
   - 100 days of data = ~50 days usable for backtest
   - Cache is essential for iteration
   - Premium tier needed for longer historical analysis
